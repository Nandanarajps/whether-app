Weather Web App

A simple browser-based weather application built for the Roadmap.sh Weather Web App project.

Roadmap.sh Project

https://roadmap.sh/projects/weather-app

Features

Search for weather by location/city.

Display current temperature.

Display wind speed.

Display likelihood of rain.

Display general weather conditions such as Sunny, Cloudy, Raining, Snow, and Thunderstorm.

Show the previous 24 hours of weather data.

Show the next 24 hours of weather data.

Refresh the weather information.

Use the browser's current location with the "My Location" button.

Technologies Used

HTML

CSS

JavaScript

Open-Meteo Geocoding API

Open-Meteo Weather API

How to Run

Download or clone this repository.

Open the project folder in VS Code.

Open index.html.

Run it using the VS Code Live Server extension, or open the HTML file directly in a browser.

Enter a city name and click Search.

API

This project uses the Open-Meteo API to retrieve weather information and its geocoding API to convert location names into coordinates.

https://open-meteo.com/
